Используй деловой русский язык. Оставь пропуски [ФИО], [Ваш Email], [Последние 4 цифры].

Сложность (difficulty) ставь "hard", так как отмена требует обращения в поддержку. Параметр source строго "llm_generated".

Ожидаемая JSON-схема (объект CancelInstruction):
{
  "subscription_id": "string",
  "service_name": "string",
  "difficulty": "hard",
  "steps": [
    "string"
  ],
  "url": null,
  "letter_template": "string",
  "source": "llm_generated",
  "savings_yearly": 0.0
}

Верни только JSON, без markdown-обёртки, без пояснений.
